# SGC Java Mini Projects

This repository contains Java mini projects developed to practice 
and improve programming skills using Object-Oriented Programming (OOP).

## Projects

### 1. University Student Record System
- Add student details
- Manage student attendance
- Store and calculate subject marks
- Calculate total marks, average, grade, and result
- Generate student report cards
- Display multiple student records

### 2. Hospital Management System
- Register patients
- Store patient details
- Manage appointment information
- Calculate consultation and estimated medicine fees
- Generate patient bills
- Display patient records

### 3. Library Management System
- Add books to the library
- Display book inventory
- Issue and return books
- Check book availability
- Calculate overdue fines

### 4. Bank Account Management System
- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Display account information

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Methods
- Arrays
- Scanner
- Conditional Statements
- Loops
- Switch Statements

## Purpose
These projects are developed for academic learning, practical 
programming experience, and understanding Java fundamentals.
